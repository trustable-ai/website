# DocumentAI

An AI-powered document management workspace.

DocumentAI is not a chatbot. Documents are the center of the experience: you
keep your documents in a library, open one in a workspace, and the assistant
works on *that* document through contextual actions. Every result comes back as
a visual block — summary cards, an extraction dashboard, a review panel, an
interactive checklist — never as a wall of chat text.

![DocumentAI](screenshot.png)

## What you can do

**Organize a document library.** Every document carries a title, type (PDF,
DOCX, TXT, Markdown), size, author, creation and modification dates, version,
category, tags and a status. Browse as cards or as a list, search, filter by
category, tag or type, and sort by any field. Each document has an actions menu:
open, rename, duplicate, archive, delete. Upload files by drag and drop, or
start a new document from scratch.

**Work on a document.** Opening a document gives you a header with an editable
title, its version, status and author, plus export, new-version and delete
controls. The body is a set of editable blocks — headings, sections, text — with
Markdown rendering, notes, comments and highlighted changes. AI results appear
as additional blocks alongside your content, so the document and its analysis
stay in one place.

**Ask the assistant.** The right-hand panel always shows which document it is
working on and offers quick actions:

- **Summarize Document** — main topic, key points, important sections
- **Extract Information** — people, dates, numbers, entities and tasks
- **Find Issues** — missing information, inconsistencies, suggestions
- **Suggested Questions** — questions the document raises
- **Generate Checklist** — an interactive checklist you can tick off
- **Create Report**, **Improve Text**, **Compare Versions**

You can also type a free-form prompt. Answers stream in as they are generated,
and you can stop a response at any time.

**Track the document lifecycle.** Create versions, compare them with added,
removed and modified sections highlighted, and restore an earlier one. Move a
document through Draft → Review → Approved → Published → Archived and follow it
on a workflow timeline. A connections view shows linked documents, references
and related topics.

**Search by meaning.** Semantic search finds documents by concept as well as by
keyword, showing matching documents with a similarity score and surfacing
related ones.

**Home dashboard.** Statistics cards (total documents, recent, under review,
created this week), a recent-documents strip with previews and last activity,
and large quick-action buttons for creating, uploading, importing and searching.

## The experience

Rounded cards and glassmorphism, dark and light mode, smooth animations,
skeleton loading states and considered empty states throughout. On the desktop
the layout is three resizable panes — library sidebar, workspace, assistant. On
mobile the same app becomes drawer navigation, bottom sheets and collapsible
panels. It is fully responsive at every size.

## How it is put together

The interface is a React and TypeScript single-page app (Vite, Tailwind CSS,
shadcn/ui, Framer Motion). Behind it runs a single serverless action on Apache
OpenServerless that talks to any OpenAI-compatible model endpoint and streams
its answers back to the browser. The action carries its own grounding knowledge,
so the assistant answers from your material rather than from the open web.

Analysis is resilient: each action produces an immediate result computed from
the document itself, then enriches it with the model's streamed response. If the
model is unreachable, you still get a useful answer.

## Getting started

```bash
npm install
npm run dev
```

Copy `.env.dist` to `.env` and set `AI_BASE_URL`, `AI_API_KEY` and
`AI_CHAT_MODEL` to point at your model endpoint. The app opens on port 5173 with
a mock document library ready to explore.
